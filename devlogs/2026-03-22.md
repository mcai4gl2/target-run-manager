## Build Failure Details Panel

### Problem / Goal
- Refactor C++ build-failure handling so the bottom-right failure popup can lead the user to the actual compiler output instead of only showing a generic error.
- Add unit test coverage for the new failure-details surface and record the change in the repository devlog.

### Problems Encountered
- The existing runner streamed build output into the extension output channel but discarded it after the build finished, so the popup had no structured source to reopen.
- The VS Code test mock did not model `Uri.toString()` or virtual text documents closely enough for a direct unit test of the new details panel, so the mock had to be extended.

### Key Design Decisions
- Used a virtual read-only document via `TextDocumentContentProvider` instead of a custom webview so the failure output opens quickly in a normal editor tab and stays simple to test.
- Captured build output inside the runner while still mirroring it to the existing output channel, preserving current behavior and avoiding provider-specific rewrites.

### Solution / Implementation
- Added `BuildFailureReport` to register a `target-run-manager-build-failure:` document provider and open build-failure details in a side editor tab.
- Refactored `Runner` build paths to buffer streamed build output, show a `Show Details` action on failure notifications, and forward the captured data to the presenter.
- Wired the presenter into extension activation and added focused tests for both the runner failure path and the presenter itself.

### Results
- `npm run compile` passed.
- `npx jest --runTestsByPath src/__tests__/ui/buildFailureReport.test.ts src/__tests__/runner/runnerClass.test.ts src/__tests__/extension.test.ts` passed.

### Files Modified
- `src/ui/buildFailureReport.ts` - added the virtual build-failure document presenter.
- `src/runner/runner.ts` - captured build output and attached a `Show Details` failure action.
- `src/extension.ts` - instantiated and registered the build-failure presenter.
- `src/__tests__/ui/buildFailureReport.test.ts` - added unit tests for the new details presenter.
- `src/__tests__/runner/runnerClass.test.ts` - added failure-details coverage for runner build failures.
- `src/__tests__/__mocks__/vscode.ts` - extended the VS Code mock for virtual document testing.
